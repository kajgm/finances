# Finances

This is a simple repo that hosts scripts for managing personal finance tracking spreadsheets.

# Installation

1. Install Node.js: https://nodejs.org/en/download/

2. Install clasp

```
npm install @google/clasp -g
```

# Setup

1. Login to clasp

```
clasp login
```

# Common commands

Pull latest changes

```
clasp pull
```

Push latest changes

```
clasp push
```

Read more here: https://developers.google.com/apps-script/guides/clasp
